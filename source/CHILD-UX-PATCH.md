# 儿童端 UX 补丁（CHILD-UX-PATCH）

> 目标：首页突出「继续今天学习」与 4 个顺序阶段；每日 4 阶段明确时长
> 朗读 **15** / 抄写 **10** / 默写 **20** / 单词 **15** = **60 分钟**；
> 每阶段走「听示范 → 尝试 → 反馈 → 订正/再来 → 完成」。
>
> **本补丁不修改 `index.html` / `app.js` / `styles.css` / `data.js` 任何一行。**
> 全部靠两个新文件运行时注入，可随时删文件回滚。

---

## 0. 集成方法（index.html 只加 2 行）

`index.html` 已有：

```html
<link rel="stylesheet" href="styles.css">
```

改为（加 1 行）：

```html
<link rel="stylesheet" href="styles.css">
<link rel="stylesheet" href="child-ux.css">   <!-- 新增 -->
```

`index.html` 末尾已有：

```html
<script src="data.js"></script>
<script src="assessments.js"></script>
<script src="app.js"></script>
```

改为（加 1 行，必须在 `app.js` **之后**）：

```html
<script src="data.js"></script>
<script src="assessments.js"></script>
<script src="app.js"></script>
<script src="child-ux.js"></script>   <!-- 新增 -->
```

> 若已集成 shadowing / typing-dictation，保持它们原有 `<script>` 位置不变，
> `child-ux.js` 放在所有学习脚本最后即可（它会自动调用 `Shadowing.refresh()`）。

## 4. 每日 4 阶段：五步流程文案（引导条动态切换）

引导条内容随当前步骤自动切换，文案与页面真实控件一一对应：

**① 朗读（15 分钟）**
1. 听示范 — 点「▶ 朗读全文」，先听一遍标准发音
2. 试一试 — 点「🎤 开始跟读」，跟着录音一句一句读
3. 看反馈 — 读错或漏读的词会变红
4. 再来一次 — 点「重录当前句」，把变红的词再读一遍
5. 打勾完成 — 勾选「朗读完成」

**② 抄写（10 分钟）**
1. 听示范 — 先听一遍朗读，读准每个词
2. 试一试 — 在练习本上对照短文工整抄写
3. 看反馈 — 抬头对照屏幕原文找漏词
4. 订正 — 补上漏掉的词和标点
5. 打勾完成 — 勾选「抄写完成」

**③ 默写（20 分钟）**
1. 听示范 — 点「▶ 播放当前句」听清楚
2. 试一试 — 在练习本写下听到的句子（或用 iPad 输入默写）
3. 看反馈 — 点「显示原文对照」逐句对
4. 订正/再来 — 错句「重听」或「只重做错题」
5. 打勾完成 — 勾选「默写完成」

**④ 单词（15 分钟）**
1. 听示范 — 点单词卡片听发音和例句
2. 试一试 — 看单词读 3 遍，记中文意思
3. 看反馈 — 复习词想「记住了吗」
4. 再来一次 — 点「没记住」，明天会再出现
5. 打勾完成 — 勾选「单词学习完成」

## 5. 状态 / 空态 / 禁用态文案约定

新增统一横幅组件 `Cux.banner(容器, 类型, 文案, 按钮, 回调)`，类型与推荐文案：

| 场景 | 类型 | 文案 | 按钮 |
|---|---|---|---|
| 单词复习到期为 0 | `ok` | 今天没有要复习的单词，太棒了！ | （无需按钮） |
| 语音识别启动中（跟读模块未来可调用） | `info` | 正在启动麦克风，请允许授权… | 禁用态 |
| 麦克风被拒绝 / 识别失败 | `err` | 没听到声音或识别失败，检查麦克风后点重试 | 「重试」 |
| 默写提交后 | `ok` | 已提交！对照红色错字订正一遍吧 | （自动消失） |
| 测评未开始，孩子端 | （整卡隐藏） | — | 家长端才可见 |
| 下一步主按钮（当前步未打勾） | 禁用 | `先打勾完成本步，再去「下一步」` | `disabled` |
| 30 天全部完成 | 首页主按钮文案 | `30 天全部完成，太棒了！` | — |

既有模块自带的降级提示（shadowing 的 `.sh-warn`、typing-dictation 的空态）**保留不动**，本补丁仅负责隐藏高级历史、不重复造提示。

## 6. 关键行为说明

- **返回不丢进度**：进度本来就存 `localStorage`（既有逻辑）。本补丁额外做：从首页再进入某一天时，自动跳到「第一个没打勾的步骤」，而不是每次都回到朗读。
- **完成给下一步**：当前步勾选后，「下一步」主按钮才点亮；点它切到下一阶段；第 4 阶段勾选后，按钮变为「去标记今日完成」并平滑滚动到底部完成栏。
- **主要按钮一致**：引导条「下一步」直接复用既有 `.footer-btn.primary` 类，配色/圆角/禁用态全站统一，不另造按钮样式。
- **家长入口位置**：放在「设置」视图顶部（齿轮 ⚙ 进入），孩子日常学习路径上看不到。
- **不堆叠装饰**：所有新元素只用既有 CSS 变量与阴影，不加渐变/插画/动画堆砌；`.cux-*` 类不与既有 `.sh-* / .td-*` 冲突。

---

## 7. 回滚方式

删除 `<head>` 里 `child-ux.css` 一行、`<body>` 末尾 `child-ux.js` 一行即可，无残留数据。
本补丁只写 1 个 localStorage key：`eng30_cux_parent`（家长视图开关），不碰 `eng30_state_v1`。
